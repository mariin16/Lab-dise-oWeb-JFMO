Para ejecutar el proyecto: 

1. Clonar o descargar el repositorio
2. Si es necesario instalar dependencias mediante "npm install"
3. Iniciar el proyecto mediante "npm run dev"
4. Abrir el link "localhost"

Modo de uso

- Las películas se pueden filtrar por año, género o clasificación
- Cada película puede verse con más detalle al darle clic
- El usuario puede marcar películas como favoritos o darle una puntuación
